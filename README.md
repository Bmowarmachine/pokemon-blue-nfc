# Pokémon Blue NFC

Sitio web estático para abrir un emulador de Game Boy desde un tag NFC.

## Flujo

1. Publica este repositorio con GitHub Pages.
2. Abre la URL del sitio una vez en el teléfono.
3. Selecciona tu archivo `.gb`.
4. La ROM se guarda solo en el navegador (IndexedDB); no se publica.
5. Escribe la URL de GitHub Pages en un tag NFC.
6. Desde entonces, al acercar el teléfono al tag, el sitio abre y el juego inicia automáticamente.
